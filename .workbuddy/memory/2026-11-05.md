## 后台逻辑审查（第二轮，非界面）

### 修掉的逻辑缺陷
1. **飞书发送成功判定错误**：`send_feishu_msg` 只判 HTTP 200，但飞书签名错误/限流(9499)
   同样返回 200（body code≠0）。改为解析业务 code，0/None 才算成功。
2. **发送失败仍写「已推送/已告警」→ 告警丢失**：meme_underval（压制 24h）、lp_apr（6h）、
   lp_alert（要等价格回中枢才重武装）、price.py、资产 RSI（latch 在发送前写库）。
   统一改为「发送成功才落标记」，资产 RSI 新增 `_send_rsi_messages()` 发送失败回滚 latch。
3. **批量 Meme 监控无去重**：每 60 分钟对同一批越界池重复推送。改用 `pump_alert_sent`
   做边缘触发（`clear_pushed` 新增：回到区间即清除记录，越界那一刻才推）。
4. **时间戳时区**：库里 `datetime('now')` 是 UTC，页面直接展示慢 8 小时。新增
   `app/interfaces/timefmt.py::to_local_display()`，dashboard / 链上代币 / 主流加密货币 /
   LP 告警 / 价格监控 五处统一转换。
5. **新增标的无去重**：`add_new_asset` 直接 INSERT，库里已有 ASTER-USDT（1W + 1D）两条，
   会重复取数+重复告警。加同 type+code（忽略大小写）校验，页面给「已存在」提示。
