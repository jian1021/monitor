# 2026-10-17

## 链上代币模块：启用 Base 链 + 加入 AERO 监控

用户要求「在链上代币模块加上 base 链，并把 aero 加入监控」。

### 排查结论
Base 链在代码层面**早已支持**，不需要新增适配：
- `app/interfaces/asset_config.py` 的 `TOKEN_CHAINS` 已含 `base`，`CHAIN_LABELS["base"]="Base"`
- `app/infrastructure/market_data/chains.py` 的 `_CHAIN_TO_DEXScreener["base"]="base"`、
  `_CHAIN_TO_GECKO["base"]="base"` 均已配置
- 后台 `main.py::run_onchain_token_monitor` 的 chain 从 DB 直读、无白名单限制

实测确认可用：
- `search_tokens("base", "AERO")` → Aerodrome `0x940181a94A35A4569E4529A3CDfB74e38FD98631`
  （流动性 $43M / 市值 $894M）
- `get_token_rsi("base", AERO, "1d", 3, 15)` → RSI 45.34 @ $0.8756（20 根日线）
- `get_token_rsi("base", AERO, "1h", 3, 5)` → RSI 81.23 @ $0.8878（125 根小时线）

### 真正的缺口：表格不显示所属链
数据库里此前 26 个 token 标的只有 sol(22) / robinhood(4)，没有任何 base 标的；
但**链上代币表格原本不显示所属链列**，加了 base 之后无法区分同名跨链代币。
`dashboard.py` 的表格一直有该列（原列名「链」）。

### 改动
1. `pages/st_onchain_token.py`：表格新增「所属链」列，值由 `CHAIN_LABELS` 映射
   （`chain` → `chain_label`，未识别的链回退显示原始值，None 回退 `sol`）。
2. `app/interfaces/asset_grid.py`：补充 `configure_column("所属链", editable=False, width=110)`。
3. `pages/dashboard.py`：原列名「链」统一改为「所属链」（含 column_config 里的 key）。
4. 写入监控标的：`add_new_asset("token", "0x940181a94A35A4569E4529A3CDfB74e38FD98631",
   "AERO", "base", "1h")` → id=127，enabled=1。周期选 1h（现有 27 个 token 中 1h 占多数，
   页面有「批量切换日线 / 1H」按钮可随时改）。

### 验证
- `load_instruments()` 后台加载确认：tokens 27 个，链分布 `sol:22 / robinhood:4 / base:1`，
  AERO 带 `chain='base'`、`timeframe='1h'` 正常进入监控循环
- 页面数据转换正确：链标签 `{'Solana (SOL)': 22, 'Robinhood (RH)': 4, 'Base': 1}`
- AppTest 冒烟 `st_onchain_token.py` / `dashboard.py` 均无异常、无 error/warning
- **204 passed**（守卫测试从 10 条增至 12 条）
