# Meteora DLMM 模块开发说明

Meteora 模块仅支持 DLMM。模块职责包括官方池发现、标准化、SQLite 持久化、候选筛选、评分、K 线指标和重点池监控。

## 代码边界

- `providers/dlmm.py`：DLMM API 请求与响应解析。
- `scanner.py`：游标分页扫描、去重、进度和断点续扫。
- `db.py`：池、快照、设置、扫描状态和错误日志。
- `filters.py`、`scoring.py`、`indicators.py`：纯规则与指标计算。
- `monitor.py`：重点池更新、快照和提醒。
- `pages/meteora_scanner.py`：Streamlit 页面。

## 约束

1. 新扫描只接受 `DLMM` 类型；不支持的池类型不得进入筛选结果和策略候选。
2. 使用 Meteora 官方返回数据，不伪造缺失指标。缺失值保留为空并在筛选结果说明。
3. API 错误写入 `api_errors`，单条数据解析失败不得中断整页扫描。
4. SQLite 数据库采用 WAL 与线程锁，扫描中断时保存游标以支持续扫。
5. 不提交本地数据库、密钥或 `.env` 文件。

## 验证
